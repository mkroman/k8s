Tips:
  * Test first with a dry run:  helm upgrade {{ .Release.Name }} --reuse-values \
                                  --set renovate.config.dryRun=full
  * Trigger a run immediately:  kubectl -n {{ .Release.Namespace }} create job \
                                  --from=cronjob/{{ include "renovate.fullname" . }} renovate-manual
  * Inspect logs:               kubectl -n {{ .Release.Namespace }} logs job/renovate-manual
  * Keep the bot updated:       bump image.tag regularly (docs recommend pinning
                                each release). https://docs.renovatebot.com/getting-started/running/#docker-images
